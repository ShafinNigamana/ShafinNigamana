## 🚀 Featured Projects

### 🛡️ **[Argus — Next-Gen Human Verification & Liveness Detection](https://github.com/ShafinNigamana/Argus)**
*Real-time biometric identity verification platform defending against deepfakes, built for Google Solution Challenge 2026.*
*   🧠 **Multi-Modal Liveness**: Extracts subtle micro-vascular blood flow pulses via **rPPG green-channel FFT analysis** alongside facial biomechanics tracking using Google ML Kit.
*   🤖 **AI Reasoning Agent**: Features an adaptive forensic reasoning agent powered by **Google Gemini 2.5 Flash-Lite** to analyze heart rate variability (HRV) and biological reflex dynamics.
*   🔐 **Google-Native Trust Ledger**: Every verification is cryptographically anchored to an immutable ledger digitally signed via **Google Cloud KMS** on **Cloud Run** and backed by **Firestore**.
*   🛠️ **Stack**: Flutter, Spring Boot 3.5 (Java 21), Google Cloud Run, Vertex AI, Google Cloud KMS, Firestore, Python FFT.

### ⚖️ **[Apna Vakeel — AI Legal Assistant for Indian Laws](https://github.com/ShafinNigamana/ApnaVakeel)**
*RAG-powered bilingual legal assistant providing cited statutory answers across Indian penal and constitutional codes.*
*   📚 **Grounded in Real Law**: Ingests and indexes 8 verified legal statutes (IPC, BNS 2023, Constitution of India, POCSO, etc.) using **FAISS vector search** and chunked semantic indexing.
*   🤖 **Bilingual RAG Pipeline**: Powered by **Groq LLaMA 3.1** with **LangChain**, delivering instant answers with exact Act and section citations in English and Hindi.
*   ⚡ **Architecture**: FastAPI backend streaming responses to a modern React frontend with built-in legal disclaimer guardrails.
*   🛠️ **Stack**: FastAPI, Python, LangChain, FAISS, Groq LLaMA 3.1, React.

### 🛡️ **[DepScan — Exploitability-First Dependency Scanner](https://github.com/ShafinNigamana/DepScan)**
*Automated vulnerability scanner prioritizing findings by real-world exploitability rather than theoretical CVSS scores.*
*   🔍 **Dual-Source Threat Intelligence**: Ingests npm (`package-lock.json` v1–v3) and Python (`requirements.txt`) manifests, batch-queries **OSV.dev** with local TTL caching, and cross-references against the **CISA Known Exploited Vulnerabilities (KEV)** catalog.
*   📊 **Weighted Risk Formula**: Computes actionable risk scores using `Risk = 0.50 × Severity + 0.35 × Exploitability + 0.15 × Exposure`.
*   🚦 **CI/CD Integration**: Supports `--fail-on high` pipeline gating, generates self-contained dark HTML/JSON audit reports, packaged with Docker, backed by **94 passing automated tests**.
*   🛠️ **Stack**: Python 3.11, Click, httpx, SQLite, Docker, pytest.
